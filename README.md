# Arus Kas

Aplikasi pencatatan arus kas berbasis CodeIgniter.

## Instalasi
1. Salin project ke folder `htdocs` (XAMPP).
2. Buat database baru, lalu import file di folder `database/`.
3. Atur koneksi di `application/config/database.php`.
4. Buka `http://localhost/arus-kas` di browser.

## Catatan
Data di folder `database/` adalah data simulasi, bukan data asli.
